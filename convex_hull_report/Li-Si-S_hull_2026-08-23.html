端点の高さは信用しすぎない

S の端点が S6 環（空間群 2）になっている。実在の α-S は Fddd(70) の S8 環で、今回 S8 は凸包の +9.2 meV/atom 上に出た。端点が数 meV ずれれば、S を多く含む相の生成エネルギーは全体がその分だけ動く。Li4SiS5 の +4.8 meV のような差は、この一点だけで反転しうる。Li と Si の端点（bcc Li / ダイヤモンド型 Si2、空間群 229 / 227）は妥当である。

届かなかった実在相

Li2SiS3 は実在する化合物だが +29.1 meV/atom で、Li2S 0.50 + SiS2 0.50 に分解すると出た。原因は 3 つ考えられる。(1) 上の端点のずれ、(2) 空間群を予測 3 位までしか見ていないので、実在の構造型が 4 位以下なら初めから届かない、(3) MatterSim の精度。Li–P–S では同じ形で β-Li3PS4 の Pnma(62) が 8 原子セルに収まらず取り逃がしている。セルの大きさが構造型を決めるので、10 原子の枠外にある相は原理的に見つからない。

数十 meV は「同じ」と読む

MatterSim は非磁性の汎用ポテンシャルで、この手法の分解能は数十 meV/atom の程度である。50 meV 以内に Li4SiS5(+4.8)・Li3SiS4(+10.5)・LiSi2S4(+20.8)・Li3SiS6(+27.3)・Li2SiS3(+29.1) の 5 件が並ぶが、この範囲の順位は入れ替わりうる。「載った / 載らない」を 10 meV の差で言い切らない。

点が出なかった組成が 13 ある

投げた 202 組成のうち 189 が図に載り、13 は点が 1 つも出ていない。Li3S2 / Li4S3 / Li5S2 / Li5S3 / Li7S2 / Li7S3 / Li3Si2 / Li3Si7 / Si4S5 / Si5S3 / Si5S4 / Li3SiS2 / Li3Si2S。生成が 0 件（体積予測が外れた、または cfg が 1 通りしかなく試行が足りなかった）か、その空間群に組成が載らなかったものである。凸包はここに穴を持ったまま描かれているので、この近傍の判定は特に弱い。

版が 2 つ混ざっている

端点の Li2S(pk 40543) と S6(pk 42218) は前日の Li–P–S 掃引の使い回しで、hknPC 上の mattersim 1.2.3 / torch 2.13.0 で計算した。今回の三元・二元は mygardenx1 上の mattersim 1.1.2 / torch 2.7.0 である。緩和の手続き（ALGORITHM_VERSIONS の run_relax）はどちらも 1.1.0 で同一なので同じ表に並べる判断をしたが、Li2S は E_form −1.411 で相図全体を支配する点であり、ここが動けば結論も動く。
