どの三元の辺か

N–Ta–Ti、Cu–Ta–Ti の辺として、同じ回で描いた。三角図の周縁に並ぶ点の高さはこの図でしか読めない。

端点が信用できるか

Ta は 229（bcc）で当たった。Ti は 194（hcp）で当たった。　端点はすべて実在相に当たっているので、高さはそのまま読んでよい。

穴

撒いた 45 組成のうち点が出なかったのは 1 組で、いずれも約分すると別のセルサイズで探索済みの組成である。実質の欠けは 0 組。

この手法の分解能

MatterSim による緩和エネルギーの差が数十 meV/atom のところでは、「凸包に載る／載らない」を言い切れない。10 meV 差で序列を断定しないこと。

aiida-shotgun-csp 6.24.0sweep = interconnect2-bin-2026-09-12spg_ranks = [1, 2, 3] / stages = all / max_atoms = 10点 64 件・安定相 3 件
