穴は「そこに相が無い」ではない

29 組成が探索していない穴である（うち辺が 27）。図の余白のうちこれだけは「相が無い」ではなく「そこを見ていない」。数え方は basis=all（gcd>1 の倍胞を含む、原子数の和 ≤ 10）。

exit 430 と穴を混ぜない

exit 430 は 3 つ試した空間群のうち 1〜2 つで Wyckoff 配置が作れなかったという意味で、残りからは構造が出ている。上の穴の数は構造の有無で数えており、exit code では数えていない。

数十 meV は分解能に近い

この手法（MatterSim + 生成的探索）の分解能は 数十 meV/atom の程度である。10 meV 差で「載る／載らない」を言い切らないこと。

端点 Ge

Ge2 は spg 227（ダイヤモンド型）、fmax 4.6e-6。実在の Ge と同じ型。

端点 N

N4 は spg 9（Cc）。実在の α-N₂ は Pa-3（205）なので別物である。fmax 0.0096。N に富む側の基準がずれている。
