Zr 端点は作り直した

最初の掃引では Zr の hcp が一度も生成されず、端点を Cmcm(63) と fcc(225) が 0.2 meV 差で分け合い、Zr2 は +356 meV に出ていた。体積予測が Zr 側で 40% 小さく（11.6 Å³/atom、実在は 23.3）、生成器が 30 回中 0 回しか組めなかったのが原因である。volume_scale=1.6 で流し直したところ Zr2 が空間群 194（hcp）で出て、fmax 2e-6 で収束し端点を取った。fcc は +1.7 meV、Zr8(194) は +0.2 meV で、順序も妥当である。

Cu 側は直していない

やり直したのは x_Cu<0.5 の 14 組成と Zr 単体 8 件だけで、Cu の多い側は volume_scale=1.0 のままである。ZrCu6(+401)・ZrCu7(+386)・Zr2Cu7(+308)・Zr3Cu7(+290) が数百 meV に出ているのは、金属間化合物としてありえない値で、相が不安定なのではなく構造が見つかっていない。Cu 端点そのもの（fcc 225）と Cu2〜Cu5 は 0.5 meV 以内に収まっているので、単体側は問題ない。

実在相との対応

CuZr の B2（空間群 221）は凸包に載った。CuZr2 の C11b（空間群 139）は +8.3 meV で、この手法の分解能の内側にある。どちらも空間群まで一致しており、当たっていると言ってよい。Cu5Zr は +11.7 meV で出たが空間群 191 で、実在の AuBe5 型（F-43m 216）ではない。Cu8Zr3(11 原子)・Cu10Zr7(17 原子)・Cu51Zr14 は 10 原子の枠に入らないので、初めから探索範囲の外である。

ZrCu2 が凸包に載っているが疑わしい

E_form −0.171 で最も深く、ZrCu(−0.129) より下に出た。しかし Cu2Zr は Cu–Zr の平衡状態図に無い組成である。空間群 191 の 3 原子セルは AlB2 型で、Laves 相（MgCu2 型は 6 原子、MgZn2 型は 12 原子）ではない。近傍の Zr3Cu7 や Zr2Cu7 が数百 meV に外れていて包が支えられていないことも併せると、この点は「周りが高いから載っている」疑いがある。

点が出なかった組成が 8 ある

投げた 47 組成のうち 39 が図に載り、Cu3Zr2 / Cu4Zr3 / Cu5Zr2 / Cu5Zr3 / Cu5Zr4 / Cu4Zr5 / Cu3Zr7 / Zr7 は点が 1 つも出ていない。前半 5 件は Cu 側なので体積を直せば出る見込みがある。Cu4Zr5 と Cu3Zr7 と Zr7 は 1.6 倍でも出なかったので、別の理由（配置が組めない、試行が足りない）である。

空間群は実質 1 つしか試せていない

spg_ranks=[1,2,3] で撒いたが、予測は多重度に原子数が載るかを見ないので、3 つのうち 2 つは exit 410 で落ちる。たとえば CuZr2(3 原子)は [139, 129, 62] と予測され、129 と 62 は 3 原子を置けない。つまりどの組成も空間群 1 つで決まっており、当たりが悪ければ挽回できない。n_candidates が 3〜6 しかない組成が多いのはそのためで、数百 meV に外れた点はここに集中している。

数十 meV は「同じ」と読む

MatterSim は非磁性の汎用ポテンシャルで、この手法の分解能は数十 meV/atom の程度である。包に近い ZrCu3(+5.2)・Zr2Cu(+8.3)・Zr4Cu(+8.5)・ZrCu5(+11.7)・Zr3Cu2(+26.9) の順位は入れ替わりうる。一方で +150 meV 以上は分解能を大きく超えているので、そちらは「近い順位の揺れ」ではなく探索の失敗を疑うべきである。
