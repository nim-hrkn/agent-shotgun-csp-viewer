Fe2Rh2 が B2 型で当たった（この図でいちばん確かなこと）

spg 221（Pm-3m）、2:2 の 4 原子胞で −104.2 meV/atom。実在の FeRh は CsCl（B2）型の規則相で、構造型が一致している。 2 原子胞の FeRh も +0.0 で同じ点に重なる。この点は三元の掃引ではなく、以前の Fe–Rh の探索由来である（別に Fe–Rh 二元図を描いた）。

Os の頂点からは端点へまっすぐ降りる

Os を含む内部 84 組成はすべて包の上（最も近い FeOsRh4 で +52 meV）。ただし Fe–Os 辺・Os–Rh 辺は 36 組成中 0 組成しか探索されていないので、Os 側の相分割は「そこに相が無い」ではなく「そこを探していない」。実在の Fe–Os は hcp 側に広い固溶域を持つ系で、この図はそれを否定する材料を持たない。

端点が信用できるか

Fe は 229（bcc）で当たった。α-Fe と同じで、基準として信用できる。 Os は 194（hcp）で当たった。実在の Os と同じで、基準として信用できる。 Rh は 166（R-3m） で出た。実在の Rh は 225（fcc）である。fcc からわずかに菱面体に歪んだ形で、収束も緩い（fmax 0.008）。素の fcc Rh は包から +7.4 meV に置かれている。

被覆

内部 84 / 84、Fe–Rh 辺 26 / 36、Fe–Os 辺 0 / 36、Os–Rh 辺 0 / 36、端点 27 / 27（≤ 9 原子）。

撒き方

原子数の和 ≤ 9 の内部（3 元素すべてを含む組成）だけを、原子数の昇順に mygarden5 : mygarden6 : mygardenx2 : laurel = 1:1:2:6 で置いた（2026-09-09 01:26〜07:08 JST）。10 原子の殻（三元 36 組成）は撒いていない。辺の二元も撒いていない。

exit 430 は穴ではない

Fe4OsRh・FeOsRh4・FeOs3Rh・FeOs4Rh・FeOs5Rh・Fe4OsRh2 の 6 件は親が exit 430 （3 空間群のうち 1〜2 つで Wyckoff 配置が作れなかった）だが、残りの空間群から構造が出ており、図に点がある。 件数を穴の数と読み違えない。

この手法の分解能

緩和は MatterSim の汎用ポテンシャルなので、数十 meV/atom の差は「載った / 載らない」を決める根拠にならない。 以下の図はどれも生成エネルギーの深さが 0〜110 meV/atom に収まっており、系全体がその分解能と同じ尺度の上にある。 安定相として青く塗られた点と、その 1〜2 meV 上にある点は、この計算では区別が付いていないと読むこと。
