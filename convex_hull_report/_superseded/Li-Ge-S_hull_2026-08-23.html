GeS2 の生成エネルギーが正である

GeS2 は E_form +0.0293 eV/atom、包から +247.5 meV/atom。実在する安定な化合物なので、これは計算の失敗である。既約の GeS2 は 3 原子セルで、実際の GeS2 は GeS4 四面体が頂点を共有して網をつくる構造であり 3 原子では組めない。Li–Si–S の SiS2 が −0.675 eV/atom（空間群 166）で妥当に出ているのと対照的で、両系を並べて「Si は二元辺が強く Ge は弱い」と読んではいけない。差は化学ではなく、片方の計算が壊れていることによる。

凸包に載った 2 相は、周りが高いから載っている疑いがある

Li3GeS4(0 meV) と LiGe2S4(0 meV) が包に載った。しかし同じ Ge–S 側の GeS2 が上のとおり失敗し、Li4GeS4 も Li2GeS3 も大きく外れている。凸包は「近傍の点より低い」ことしか言わないので、近傍が軒並み高く出れば、そうでもない相が載る。この 2 相を「予測が当てた」と読むのは早い。

届かなかった実在相

Li4GeS4 は Li–Ge–S の代表的な固体電解質（thio-LISICON）だが +157.9 meV/atom。9 原子セルで空間群 12 を撒き、緩和後は 6 に落ちた。実際の Li4GeS4 は Pnma(62) で、9 原子では組めない。Li–P–S でも β-Li3PS4 の Pnma(62) を 8 原子セルで取り逃がしており、同じ形の失敗である。セルの大きさが構造型を決めるので、原子数を増やさない限り届かない。Li2GeS3(+222.9 meV, 6 原子) も同様。

点が出なかった組成が 42 ある

投げた 202 組成のうち 160 しか図に載っていない。Li–Si–S の穴が 13 だったのに対し 3 倍以上で、しかも Ge2S / Ge2S3 / Ge3S4 / Ge4S3 / Ge4S5 / Ge5S3 / Ge5S4 / Ge7S3 と Ge–S 二元に集中し、Li2Ge3S3 / Li2Ge4S3 / Li3Ge2S4 のような Ge の多い三元にも広く空いている。生成が 0 件（体積予測が外れた、cfg が 1 通りで試行が足りない）か、その空間群に組成が載らなかったものである。Ge 側は点が疎なまま凸包を描いているので、この領域の判定は特に弱い。

数十 meV は「同じ」と読む

MatterSim は非磁性の汎用ポテンシャルで、分解能は数十 meV/atom の程度である。包に近い三元は LiGeS2(+10.4)・LiGe2S3(+23.4)・LiGe3S5(+53.7) と続くが、この範囲の順位は入れ替わりうる。上に挙げた +158 meV や +223 meV は分解能を大きく超えているので、そちらは「近い順位の揺れ」ではなく別の原因（セルの大きさ、生成の失敗）を疑うべきである。

版が 2 つ混ざっている

端点の Li2S(pk 40543) と S6(pk 42218) は前日の Li–P–S 掃引の使い回しで、hknPC 上の mattersim 1.2.3 / torch 2.13.0 で計算した。今回の三元・二元は mygardenx1 上の mattersim 1.1.2 / torch 2.7.0 である。緩和の手続き（ALGORITHM_VERSIONS の run_relax）はどちらも 1.1.0 で同一なので同じ表に並べる判断をしたが、Li2S は E_form −1.411 で相図全体を支配する点である。
