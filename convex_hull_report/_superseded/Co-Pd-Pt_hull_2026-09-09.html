この系が、他の 2 枚の但し書きになっている

Ni–Pt–Rh では三元が 5 つ載ったが、あちらは辺を 1 組成も撒いていない。 ここでは Co–Pt 辺が埋まっており、その二元が深さ −89 〜 −109 meV で包を取ったので、三元は 120 組成のうち 2 つしか残らなかった。 同じ掃引・同じパラメタで両方を見ているので、差は「辺が有るか無いか」に帰せる。

残った三元 2 つは Pt に富む側にある

CoPd2Pt5 と CoPdPt6 はどちらも Pd–Pt 辺の近くで、その辺（Pd–Pt）と Co–Pd 辺は未探索である。実在の Pd–Pt と Co–Pd はどちらも規則相で知られる系ではないので、この 2 つが辺を埋めたときに落ちる見込みは Ni–Pt–Rh の 5 つよりは小さいが、確かめてはいない。 次に近いのは Co3PdPt4 の +12.7 meV。

Co–Pt の 4 つのうち 3 つは実在の規則相である

Co3Pt・CoPt・CoPt3 は実在の Co–Pt 状態図の規則相で、とくに CoPt が spg 123（L10、正方晶）で出たことは構造型まで一致している。 Co3Pt5 は実在の平衡相として知られていないが、CoPt と CoPt3 を結ぶ線から 2.7 meV 下にあるだけで、分解能の内側である。詳しくは別に描いた Co–Pt 二元図を見ること。

形が 1 種類に偏ることについて

包に載った三元相がどれも空間群 123（P4/mmm）なのは、層状の規則相が実際に有利だからでもあるが、1 組成につき空間群を上位 3 つしか試していない（spg_ranks = [1,2,3]）ことの反映でもある。「123 以外の形が無い」とは読まないこと。

端点が信用できるか

Co は 194（hcp）で当たった。α-Co と同じで、基準として信用できる。 Pd は 194（hcp） で出た。実在の Pd は 225（fcc）である。収束が緩く（fmax 0.010）、fcc Pd との差はこの手法の分解能の内側にある。 Pt は 225（fcc）で当たった。実在の Pt と同じで、基準として信用できる。 Co と Pt は実在どおり、Pd だけが違う。 深さを支えている Co–Pt 側の 2 端点が両方とも当たっているので、−109 meV という深さは 3 系の中でいちばん信用できる。

被覆

内部 120 / 120（穴なし）、Co–Pt 辺 44 / 45、Co–Pd 辺 0 / 45、Pd–Pt 辺 0 / 45、端点 27 / 30（Pt9・Pd9・Co5 が欠け）。畳んだあとの点は 193、緩和構造は 1512 件。

exit 430 は穴ではない

CoPd2Pt・Co2Pd2Pt・CoPd7Pt・CoPd5Pt3・CoPd3Pt5・Co3Pd6Pt・Co4Pd5Pt・Co5Pd4Pt・Co5Pd3Pt・Co6Pd2Pt・Co6PdPt2・Co6PdPt・Co7PdPt が exit 430 で終わったが、いずれも構造は出ていて図に点がある。

撒き方

原子数の和 ≤ 10 の内部（3 元素すべてを含む）120 組成を、原子数の昇順に mygarden5 : mygarden6 : mygardenx2 = 2:2:6（24 / 24 / 72 件）で置いた。3 系 360 件を 2026-09-09 07:52 に置き、15:20 に終わっている（7 時間 28 分）。パラメタは既定（spg_ranks = [1,2,3] / stages = all / n_cfgs 既定）。辺の二元と端点は今回撒いていない。 図に出ている端点は以前の探索由来である。

辺を撒いていないことは、どちらの結論に効くか

点を足すと下側凸包は下がることしかない。 だから「包に載らなかった」は辺（二元）を埋めても覆らないが、「包に載った」は覆りうる。 三元相が載ったという結論のほうが常に弱い。この 3 系のうち辺が埋まっているのは Co–Pd–Pt の Co–Pt 辺だけで、そこでは実際に二元 4 つが包を作り、三元は 120 組成のうち 2 つしか残らなかった。 他の 2 系の三元相は、この検定をまだ受けていない。

この手法の分解能

緩和は MatterSim の汎用ポテンシャルなので、数十 meV/atom の差は「載った / 載らない」を決める根拠にならない。 以下の図はどれも生成エネルギーの深さが 0〜110 meV/atom に収まっており、系全体がその分解能と同じ尺度の上にある。 安定相として青く塗られた点と、その 1〜2 meV 上にある点は、この計算では区別が付いていないと読むこと。
