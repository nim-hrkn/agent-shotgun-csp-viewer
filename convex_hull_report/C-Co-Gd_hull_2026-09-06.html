穴は「そこに相が無い」ではない

29 組成が探索していない穴である（うち辺が 18）。図の余白のうちこれだけは「相が無い」ではなく「そこを見ていない」。数え方は basis=all（gcd>1 の倍胞を含む、原子数の和 ≤ 10）。

exit 430 と穴を混ぜない

exit 430 は 3 つ試した空間群のうち 1〜2 つで Wyckoff 配置が作れなかったという意味で、残りからは構造が出ている。上の穴の数は構造の有無で数えており、exit code では数えていない。

数十 meV は分解能に近い

この手法（MatterSim + 生成的探索）の分解能は 数十 meV/atom の程度である。10 meV 差で「載る／載らない」を言い切らないこと。

端点 C

C2 は spg 187（P-6m2）。黒鉛（194）に近い層状の積み方だが同一ではない。fmax 8.1e-6 で収束は良い。

端点 Co

Co2 は spg 194（hcp）、fmax 9.2e-7。実在の Co と同じ型で、よく収束している。

端点 Gd

Gd8 は spg 62（Pnma）で出た。実際の Gd は hcp（P6₃/mmc, 194）であり、この端点は別の構造型である。しかも fmax 0.0086 で収束が甘い。セルサイズに 2 原子が無く hcp を組めなかったことが原因と考えられる。Gd に富む側の高さはこの端点の誤差をそのまま含む。
